# Происхождение береговой линии

Основной источник — изображение карты **1024×1024**, предоставленное пользователем в этом диалоге. Независимая проверка его версии игры, официального происхождения и географической полноты не проводилась. Оригинальный JPEG не включён в репозиторий: распространяются извлечённые контуры, маска и параметры воспроизведения.

SHA-256 исходного файла:

~~~text
de6eac28ebb92e30501927f5ab8fa2621247249ae98b994b1945e52f32297f3a
~~~

## Обработка

Скрипт [tools/vectorize_user_map.py](tools/vectorize_user_map.py) читает [data/user-map-profile.json](data/user-map-profile.json). Он обрезает декоративную рамку, исключает область розы ветров и нижнего орнамента, выделяет светлые контуры по отношению каналов R/B и G/B, замыкает разрывы дисковым фильтром радиуса 2 пикселя, заполняет внутренности и удаляет компоненты меньше 20 пикселей. Замкнутые внутренние водоёмы заполняются: результат показывает морской берег, без рек и рельефа.

После просмотра исходника добавлена **одна ручная направляющая шириной 2 пикселя** в узком проливе к востоку от Фонтейна. Она предотвращает ошибочное соединение соседних участков суши при замыкании линии. Её точные координаты и причина записаны в профиле. Остальные контуры получены алгоритмически; неизвестная география не дорисовывалась. Генеративная перерисовка для геометрии не использовалась.

Границы пикселей преобразуются в замкнутые полигоны с сохранением раздельных компонентов. Контуры упрощены алгоритмом Рамера — Дугласа — Пекера с допуском 0,6 пикселя. Итог: **35 полигонов / 4007 вершин**, охват в исходнике [113, 101, 889, 813]. Ширина 776 пикселей соответствует 20 000 км, то есть **25,773 км на пиксель**; вертикальный масштаб тот же. Север направлен вверх, без поворота карты.

## Точность

Текстура воды, JPEG-сжатие, одинаковый с водой цвет части суши и местами слабая береговая линия ограничивают точность. Фильтр может сгладить узкие бухты и объединить близкие острова; часть мелких островов удалена вместе с шумом. Несколько пикселей ошибки здесь дают десятки километров условного масштаба. Допуск упрощения не является оценкой общей ошибки сегментации. GeoJSON описывает вымышленную планету; координаты не являются реальной географией Земли.

SVG можно использовать как основу для дальнейшей ручной правки. Его viewBox сохраняет координаты исходных пикселей, поэтому контуры можно совместить с оригиналом в векторном редакторе. Чёрная линия на прозрачном фоне — только извлечённый берег, без рамки, компаса и рельефа.

## Воспроизведение

~~~bash
python -m pip install -r requirements-tools.txt
python tools/vectorize_user_map.py /path/to/original-image.jpg
~~~

Скрипт проверяет размер и SHA-256, чтобы не применить профиль к другой картинке. Для другого изображения сначала требуется подходящий профиль. Готовое приложение запускается без пакетов обработки изображений.

Результаты: [JSON](data/coastline.json), [SVG](data/coastline.svg), [GeoJSON](data/coastline.geojson), [маска](data/coastline-mask.png), [предпросмотр](data/coastline-preview.png). Подписи регионов и демо-метки приблизительные, помещены по этому изображению и не являются официальными координатами населённых пунктов.
