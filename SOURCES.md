# Происхождение контуров

- Официальная интерактивная карта Тейвата: https://act.hoyolab.com/ys/app/interactive-map/index.html
- Использованный доступный снимок игровой карты: **genshin-base/teyvat-map**, ветка `images`, commit **d522efa9bbd44894ccaef79731eb04a634d016d6**: https://github.com/genshin-base/teyvat-map/tree/d522efa9bbd44894ccaef79731eb04a634d016d6
- Описание зеркала и сборки игровых тайлов: https://github.com/genshin-base/teyvat-map
- Снимок соответствует карте с Фонтейном эпохи 4.0; актуальность относительно официальной карты не заявляется.

Использованы 12 JPEG-тайлов уровня `tiles/teyvat/jpg/-4/`:

```text
-2/-1.jpg  -2/0.jpg  -2/1.jpg
-1/-1.jpg  -1/0.jpg  -1/1.jpg
 0/-1.jpg   0/0.jpg   0/1.jpg   0/2.jpg
 1/0.jpg    1/1.jpg
```

Оригинальные игровые текстуры не входят в репозиторий. Для воспроизведения скачайте эти файлы из закреплённого commit, сохранив папки `<x>/<y>.jpg`. SHA-256 каждого исходного файла записан в `data/coastline.json`.

```bash
python -m pip install Pillow
python tools/extract_coastline.py --tiles /path/to/downloaded/tiles
```

Алгоритм собирает снимок 1024 × 1024, отделяет цвет суши от воды, применяет медианный фильтр и морфологическое замыкание, заполняет замкнутые внутренние водоёмы, удаляет компоненты площадью менее 6 пикселей и упрощает контуры алгоритмом Рамера — Дугласа — Пекера. Полная ширина полученных островов и материка соответствует 20 000 км; вертикальный масштаб сохраняется. В контуре 62 компоненты суши, 1405 вершин.

Соседство с чёрной областью исходного снимка отмечается как `frontiers` и показывается пунктиром: это неизвестная граница, не морское побережье. Автоматическое разделение воды и суши приблизительно: особенно неточны мелкие острова, мелководья и края снимка. Это пригодная для прототипа подложка, а не картографическая съёмка.

Нормализация к планете, координаты региональных подписей и демонстрационные метки — условности этого приложения. Они не предоставлены HoYoverse. Сегментация и отсечение малых объектов не дают гарантии топологической точности.
